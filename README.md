# Student Performance Analytics System

## Objective

This project is used to analyze student performance using Python, NumPy and Pandas. It calculates marks, averages, grades, pass/fail results and performs basic subject-wise analysis.

## Technologies Used

- Python
- NumPy
- Pandas

## Dataset

The dataset contains 20 student records. It includes Student ID, Name, Department, marks in six subjects and Attendance.

## Subjects

- Python
- Maths
- English
- Physics
- Chemistry
- Biology

## Features

- Read student data from CSV file
- Display student information
- Calculate total marks
- Calculate average marks
- Assign grades
- Identify pass/fail students
- Find highest and lowest average
- Calculate class average
- Calculate subject-wise average
- Find the best subject
- Identify top-performing students

## How to Run

1. Install Python.
2. Install Pandas and NumPy.
3. Keep `main.py` and `students.csv` in the same folder.
4. Run the following command:

python main.py
